# BGM 背景音乐

悬浮迷你播放器的静态背景音乐存放目录。

## 添加/替换曲目

将音频文件（`mp3` / `ogg`）放入本目录，文件名需与 `src/data/bgm.js` 中
对应曲目的 `src` 路径一致（当前为 `/bgm/xxx.mp3`）：

| 曲目 | 显示名 | 期望文件名 |
|------|--------|-----------|
| 私有化の小曲 | 游京 | `私有化小曲-游京DJ.mp3` |
| 购买力の小曲 | Andalusia | `购买力の小曲-Hi-Res无损音质-Andalusia.mp3` |
| 收入公开の小曲 | 暗里着迷（1993年刘德华演唱的粤语流行歌曲） | `公布收入小曲-吉他的天空-暗里着迷.mp3` |
| 汽修工の黄粱一梦小曲 | 起风了-纯音乐 | `汽修工黄粱一梦的小曲-收入结算的小曲-起风了纯音乐-高桥优.mp3` |

> 受版权限制，本仓库默认不托管受版权保护的音频。将对应音频放入后，播放器中
> 即可选择播放。未放置音频的曲目会自动置灰并标记「待添加音频」。
