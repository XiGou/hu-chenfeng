# BGM 背景音乐

悬浮迷你播放器的静态背景音乐存放目录。

## 添加/替换曲目

将音频文件（`mp3` / `ogg`）放入本目录，文件名需与 `src/data/bgm.js` 中
对应曲目的 `src` 路径一致（当前为 `/bgm/xxx.mp3`）：

| 曲目 | 期望文件名 |
|------|-----------|
| 户晨风小曲 | `hu-chenfeng-xiaoqu.mp3` |
| 游京 | `youjing.mp3` |
| 《购买力的小曲》· Andalusia | `andalusia.mp3` |
| 收入公开小曲 · 暗里着迷 | `anlizhaomi.mp3` |
| 起风了 · 纯音乐 | `qifengle.mp3` |

> 受版权限制，本仓库默认不托管受版权保护的音频。将对应音频放入后，播放器中
> 即可选择播放。未放置音频的曲目会自动置灰并标记「待添加音频」。
